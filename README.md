# HeartEye

A creative Python animation built with Tkinter, transforming random characters into a beautiful visual experience.

## Features

- ASCII-style eye animation
- Smooth zoom and camera movement
- Realistic blinking effect
- Animated heart formation using letters
- Random sparkling stars
- Interactive restart with mouse click
- Dynamic window resizing

## Technologies Used

- Python
- Tkinter
- Math
- Random
- Time

## How to Run

1. Make sure Python is installed.
2. Clone or download this repository.
3. Run the following command:

```bash
python HeartEye.py
```

## Interaction

Click anywhere on the window to restart the animation.
